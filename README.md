# orphivia

Natural text-to-speech for every voice. Type anything, choose a voice, apply a style, and listen instantly.

## Features

- **Text-to-Speech**: Convert text input into natural-sounding speech using the Web Speech API.
- **Voice Selection**: Browse and search through available voices on your device.
- **Voice Styles**: Apply different styles to customize the speech output.
- **Playback Controls**: Play, pause, resume, stop, and reset speech playback.
- **Waveform Visualization**: Visual representation of the audio output.
- **History Panel**: Keep track of previous speech generations.
- **Settings**: Customize application preferences.

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/Alfredmwange/orphivia.git
   cd orphivia
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm start
   ```

   The application will open in your browser at `http://localhost:4200`.

## Usage

1. Enter your text in the text input area.
2. Select a voice from the voice selection panel.
3. Choose a voice style if desired.
4. Click "Play speech" to start text-to-speech conversion.
5. Use playback controls to pause, resume, or stop the speech.
6. View your speech history in the history panel.

## Technologies

- **Angular**: Frontend framework
- **TypeScript**: Programming language
- **Web Speech API**: For text-to-speech functionality
- **RxJS**: Reactive programming library
